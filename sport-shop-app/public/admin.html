Cập nhật hàng từ Sapo

1. Xuất danh sách sản phẩm từ Sapo (Excel).
2. Chạy: python tools/sapo_xlsx_to_json.py file.xlsx san-pham.json
3. Chọn file san-pham.json bên dưới. Nếu dùng backend Spring Boot: bỏ bước 2, chọn thẳng file Excel (.xlsx) từ Sapo. Ảnh, tên hiển thị và mô tả bạn đã nhập được giữ nguyên; sản phẩm không còn trong file sẽ bị ẩn.
