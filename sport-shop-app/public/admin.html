Cập nhật hàng từ Sapo

Cách nhanh nhất: xuất Excel từ Sapo rồi bấm cap-nhat-web.bat (tự đọc Excel, nhập và xuất web).

Cách tay: chạy python tools/sapo_xlsx_to_json.py file.xlsx san-pham.json rồi chọn file san-pham.json bên dưới. Nếu dùng backend Spring Boot: chọn thẳng file Excel (.xlsx). Ảnh, tên hiển thị và mô tả đã nhập được giữ nguyên; sản phẩm không còn trong file sẽ bị ẩn.
